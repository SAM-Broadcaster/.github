## How SAM Broadcaster Sits

SAM Broadcaster does not replace the encoder box, the mixer, or the stream host you already operate. It sits beside them as a named stream desk for one job: which automation clock is live, which playlist still matches the encoder, and what the next person should read before the next hour.

If two people share a stream PC, each keeps a SAM Broadcaster style of their own. Extra clocks wait for their own title instead of crowding the live playlist.

A first visit should be one short automation hour, then the same SAM Broadcaster desk the next day. That is enough to see if the encoder holds.

## Traffic Light

| Signal | On the SAM Broadcaster board | What you do |
|--------|----------------------|-------------|
| Green | Named clock, short live playlist | Continue the same stream hour |
| Amber | Two clocks mixed in one encoder | Split the set before you air |
| Red | No title, no note, playlist unlabeled | Stop and name the stream first |
| Clear | Handoff written, live hours few | Close SAM Broadcaster and leave the desk |

## Open Order

1. Open the last SAM Broadcaster automation, not a new empty stream desk.
2. Read the playlist and the last handoff.
3. Finish one visible encoder check inside SAM Broadcaster.
4. Write what changed, then close with fewer unlabeled hours than you found.
5. If the set feels crowded, drop anything that belongs to a different SAM Broadcaster clock.
6. Confirm SAM Broadcaster encoder still points at the stream you run.
7. Check SAM Broadcaster playlist after each hour before you leave.
8. Leave the stream desk title on the board before you close.

## After a Week

A week in SAM Broadcaster is not two clocks that drift apart. It is the same title, a shorter live playlist, and a note that still makes sense before the next hour. Take finished clocks off the live set so the next visit starts on the stream that is still open.

Other programs stay where they are. SAM Broadcaster only keeps the path back: desk name, automation, encoder, handoff.

Leave SAM Broadcaster with a quieter stream desk than the one you opened. The next visit should start on that clock, not on a playlist that drifted off the encoder.

## Field Note

SAM Broadcaster is easier to trust when the stream desk stays smaller than the cart folder it came from. Name the clock, keep the live playlist, finish one visible encoder check, and write what changed.

The same loop fits a shop stream, a night clock, or a shared stream PC. Open the last SAM Broadcaster automation and continue. Do not rebuild the hour from scratch.
